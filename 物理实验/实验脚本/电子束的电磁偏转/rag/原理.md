## 四、思考题

1. 由电偏转灵敏度的计算结果,能得出 $\varepsilon$ 与 $U_{2}$ 有什么关系?

由式 $\varepsilon=ke\frac{1}{U_{2}}$ 知， $U_{2}$ 越大， $\varepsilon$ 越小，即 $\varepsilon$ 与 $U_{2}$ 成反比关系。

2. 偏转量的大小与光点的亮度是否有关？为什么？

有关，偏转量的大小会影响聚焦，从而影响光点亮度。

3. 地球表面的磁场对电子显像管中电子的运动有多大影响？能否忽略？

地磁场强度为 $(2.5\sim6.5)\times10^{-5}$ T，与电子显像管中磁场相比，磁场强度很弱，因此地磁场对电子显像管中电子的运动影响很小，从而可以忽略。

D = [-16.0, -12.0, -8.0, -4.0, 0, 4.0, 8.0, 12.0, 16.0];

UDx\_800 = [-31, -25, -15, -8, 0, 8, 16, 23, 30];

slope\_1000 = polyfit(UDx\_1000, D, 1);
slope\_800 = polyfit(UDx\_800, D, 1);

figure('Position', [100, 100, 800, 600]);

plot(UDx\_1000, D, 'bo', 'MarkerSize', 8, 'MarkerFaceColor', 'b', 'LineWidth', 1.5);
hold on;
plot(UDx\_800, D, 'rs', 'MarkerSize', 8, 'MarkerFaceColor', 'r', 'LineWidth', 1.5);

x\_fit = linspace(min(UDx\_1000), max(UDx\_1000), 100); % 使用UDx范围来创建拟合线
y\_fit\_1000 = polyval(slope\_1000, x\_fit); % 这里不再需要重新计算拟合，直接使用已有的斜率
y\_fit\_800 = polyval(slope\_800, x\_fit);
plot(x\_fit, y\_fit\_1000, 'b-', 'LineWidth', 2.5);
plot(x\_fit, y\_fit\_800, 'r-', 'LineWidth', 2.5);
